About this preview

The legacy tree at phylogenetic-tree.html hand-encodes topology in a JS object literal and forces every leaf to "present day", which makes the time scale meaningless. This page replaces both:

  • Data is in data/phylogeny.json, separate from the renderer.
  • Each node's time_mya + time_source citation is auditable.
  • Layout is a true chronogram (x = real MYA), not a cladogram.
  • The tools/validate.mjs script checks every leaf's URL exists and that no child is older than its parent.
